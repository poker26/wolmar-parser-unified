# Исправление поиска монет Святой Елены

## Проверенный случай

Запрос `1f86f6d2-7cd9-4d9d-b7b1-97847a59fa10` относится к серебряной монете
Святой Елены номиналом один фунт 2024 года. На фотографиях пользователя видны
надписи `ST. HELENA`, `ONE POUND`, `ONE OUNCE` и `999 SILVER`. На оборотной
стороне изображена пума на камне.

Каталожный тип `780801` совпадает по эмитенту, году и номиналу. На его оборотной
стороне изображён снежный барс. Фотографии пользователя и фотографии типа
показывают разные монеты. Поэтому тип `780801` нельзя предлагать или сохранять
для этого экземпляра.

В каталоге нет типа для монеты с пумой. Проверенный результат распознавания
сейчас имеет значение `not_found`. Точный тип можно будет связать после того,
как каталог получит проверенную запись и фотографии этой монеты.

## Причина пропуска

Модель указала страну `United Kingdom`, хотя буквальная надпись на монете
содержит `ST. HELENA`. Каталог хранит один и тот же самостоятельный эмитент в
двух написаниях: `Saint Helena` и `St. Helena`. Прежний SQL-запрос искал только
одно написание. Из-за этого строгая проверка не получала тип `780801` при
нормализованном значении `Saint Helena`.

Исправление выполняет четыре операции.

1. Буквальная надпись `ST. HELENA` получает приоритет над ошибочным названием
   государства из ответа модели.
2. Самостоятельный эмитент получает каноническое имя `Saint Helena`.
3. SQL-запрос проверяет оба каталожных написания и удаляет повторы по `id`.
4. Строгий отбор отклоняет кандидата, если распознанный и каталожный сюжеты
   содержат разные однозначные признаки. Для проверенного случая конфликтуют
   пума и снежный барс.

Совместный эмитент `Saint Helena & Ascension`, группа `St. Helena Dependencies`
и название из трёх территорий остаются отдельными сущностями. Исправление не
приравнивает их к самостоятельной Святой Елене.

## Аналогичные написания

Аудит работал в режиме чтения. Среди 726 значений страны для иностранных типов
он нашёл шесть групп, которые различаются только написанием:

| Каноническое имя | Варианты в каталоге | Типов |
| --- | --- | ---: |
| Isle of Man | `Isle of Man`, `Isle Of Man` | 2 447 |
| Turks and Caicos Islands | `Turks and Caicos Islands`, `Turks & Caicos Islands` | 385 |
| Saint Helena | `Saint Helena`, `St. Helena` | 78 |
| Saint Helena & Ascension | `Saint Helena & Ascension`, `Saint Helena And Ascension` | 60 |
| Curaçao | `Curaçao`, `Curacao` | 18 |
| Réunion | `Réunion`, `Reunion` | 17 |

Матчер теперь запрашивает варианты написания из этих шести проверенных групп.
Он не применяет общее нечёткое сравнение стран и не объединяет похожие
исторические или политические сущности.

## Проверка и выпуск

Восемь модульных тестов проверяют положительные и отрицательные варианты
эмитентов и конфликт сюжетов. Существующие тесты ожидания записи трассы и
подготовки изображений также прошли.

Повтор запроса через функции выпущенного сервера дал такой результат:

```json
{
  "country": "Saint Helena",
  "query_countries": ["Saint Helena", "St. Helena"],
  "retrieved_type_ids": [385523, 780801],
  "rejected_subject_conflict_type_ids": [780801],
  "response_candidate_ids": [],
  "catalog_match": "not_found"
}
```

Сервер использует образ
`numismatics-numis-web:foreign-issuer-aliases-20260914`. SHA-256 файла
`/app/refserver.py` имеет значение
`d590ea11b1a0e34b37fba5062fc627ec18a38c520ef262d1c1d328b8c8721fbd`.
Проверка `/refhealth` завершилась успешно. Предыдущая конфигурация и исходный
`refserver.py` сохранены в каталоге
`/opt/numismatics/backups/foreign-issuer-aliases-20260914T182419Z`.

Исправление не меняло каталог, связи коллекции или исторические результаты
распознавания.

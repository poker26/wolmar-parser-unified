# Один `XF` против ungraded-пула — исторический backtest 2026-08-31

## Вопрос

Действующий единый механизм для неслабированной коллекционной монеты использует
эвристический `XF`. Если найден хотя бы один проход того же типа в `XF`, он
выбирается вместо более широкой выборки лотов без указанного состояния.

Проверялся только этот выбор центральной оценки. Код расчёта, production-БД,
сохранённые прогнозы и процессы не изменялись.

## Методика

Один read-only запрос прочитал 94 665 пригодных `XF`/ungraded-продаж 10 670
недрагоценных типов. Для каждого типа использовался максимум один случай:

1. фактический результат — первая `XF`-продажа, перед которой существовала
   ровно одна более ранняя `XF`-продажа в другом аукционе;
2. оценка `single XF` — цена этой единственной предыдущей `XF`-продажи;
3. альтернативная оценка — действующая шестимесячная recency-weighted медиана
   минимум трёх более ранних ungraded-продаж того же типа;
4. в обе выборки попадали только продажи строго раньше целевой; тот же аукцион
   исключался;
5. связи со статусом `conflict`, бумажные деньги и драгоценные металлы
   исключались.

Так сформировано 986 пар без утечки будущих продаж.

## Результат

| Метрика | Один предыдущий `XF` | Ungraded-медиана |
|---|---:|---:|
| MdAPE | **28,3%** | 65,4% |
| P75 APE | **69,2%** | 184,5% |
| P90 APE | **152,0%** | 673,4% |
| Победы в парном сравнении | **675 (68,5%)** | 305 (30,9%) |

Шесть случаев дали одинаковую ошибку. Преимущество одного точного `XF`
сохраняется при любом размере альтернативного пула:

| Более ранних ungraded-продаж | Случаев | MdAPE одного `XF` | MdAPE ungraded | Победы `XF` / ungraded |
|---:|---:|---:|---:|---:|
| 3–5 | 423 | **26,8%** | 65,7% | 292 / 130 |
| 6–10 | 275 | **24,6%** | 62,5% | 196 / 76 |
| 11+ | 288 | **34,5%** | 73,4% | 187 / 99 |

Крупнейшие расхождения объясняют результат: ungraded-пулы ряда типов содержат
редкие разновидности, неразмеченную высокую сохранность либо иные дорогие
экземпляры. Увеличение числа таких строк не делает их более сопоставимыми с
обычным `XF`.

## Решение в рамках текущей архитектуры

Центральную оценку не менять: один проход того же типа и грейда статистически
полезнее широкой ungraded-выборки. Смешивание этих пулов или замена `XF` на
ungraded-медиану не подтверждены данными.

Отдельно остаётся проблема представления неопределённости: для одного аналога
действующий механизм возвращает `low = median = high` при confidence `0,6`.
Этот backtest подтверждает выбор медианы, но не подтверждает нулевую ширину
диапазона. Возможное расширение диапазона должно калиброваться отдельно и не
должно менять центральную оценку либо подмешивать ungraded-цены.

## Калибровка диапазона одного аналога

Повторный проход по той же когорте рассчитал отношение фактической следующей
`XF`-продажи к цене единственного предыдущего `XF`:

- P10: `0,397`;
- P25: `0,693`;
- медиана: `0,992`;
- P75: `1,252`;
- P90: `2,084`.

Медиана около единицы дополнительно подтверждает несмещённость центральной
оценки. Покрытие симметричных мультипликативных диапазонов:

| Диапазон вокруг оценки | Покрытие следующей `XF`-продажи |
|---|---:|
| `/1,5 … ×1,5` | 56,7% |
| `/2 … ×2` | 75,2% |
| `/3 … ×3` | 87,4% |
| `/5 … ×5` | 94,7% |

Разбивка по эрам не даёт основания считать один узкий диапазон точным для всех
монет: P10–P90 равен примерно `0,57–2,72` для foreign (96 случаев),
`0,40–2,00` для imperial (651) и `0,35–2,13` для USSR (214).

### Реализованный контракт представления

1. `median` и выбор единственного точного `XF` не изменены.
2. При одном проходе общий `ValuationService` возвращает
   `estimateKind=single_comparable`, `rangeAvailable=false`, центральную оценку
   в `median` и не публикует `low/high`.
3. Клиенты показывают такой результат как «Ориентир», без фиктивного диапазона.
4. При нескольких проходах остаются `estimateKind=market_range`,
   `rangeAvailable=true` и действующие `low/median/high`.
5. Внутри `collection_valuation` одиночная оценка по-прежнему хранится как
   `low=median=high`: это сохраняет ограничения таблицы и агрегатные запросы,
   но семантика фиксируется в `basis` и единообразно преобразуется на чтении.
6. Эмпирически очень широкий диапазон для одного прохода не внедрён: он создавал
   бы видимость более точного знания, чем дают данные.

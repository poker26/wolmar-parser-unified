создавались, связи лотов и каталог не изменялись. Использован текущий production

монеты. Использовать его как признак качества импорта нельзя.

## Пилотная калибровка

Выбрано 65 типов, стратифицированных по источнику Краузе, диапазону цены XF и
числу пригодных продаж. Для каждого типа общий production-оценщик был вызван без
записи результата.

- Оценка получена для 63 типов, отказ — для 2.
- Отношение `текущая оценка в рублях / цена XF Краузе в долларах`:
  - P10: 2,07;
  - P25: 8,10;
  - медиана: 32,39;
  - P75: 98,76;
  - P90: 244,54.
- Даже для 18 случаев с не менее чем пятью аналогами и confidence не ниже 0,75
  разброс не исчезает: P10 = 0,10, медиана = 32,39, P90 = 244,54.
- Медианы по диапазонам цены Краузе различаются:
  - до $5: 65,00;
  - $5–24: 17,40;
  - $25–99: 28,00;
  - от $100: 6,12.

## Вывод

Единый множитель «доллар Краузе → текущий рубль» данными не подтверждается.
Внедрение медианного коэффициента сейчас даст систематически неверные оценки.
Причины, которые нельзя смешивать в одной цифре:

1. ошибки извлечения отдельных каталоговых цен;
2. ошибочные или слишком широкие связи `лот → тип`;
3. реальная нелинейность рынка: дешёвые, дорогие и драгоценные монеты меняются
   относительно старой каталожной цены по-разному.

## Предлагаемая архитектура fallback (не реализована)

1. Аукционные проходы остаются первым и основным источником общего
   `ValuationService`.
2. Краузе используется только при недостатке проходов и только после отдельного
   quality gate для конкретной каталоговой цены.
3. Калибровка строится не одним множителем, а как минимум раздельно по ценовому
   диапазону и металлу; необходимость дополнительных сегментов проверяется на
   данных, а не задаётся заранее.
4. Для обучения и проверки берутся только пары с надёжной каталоговой ценой и
   сильной аукционной выборкой; контрольная часть не участвует в подборе модели.
5. Fallback возвращает диапазон и пониженную уверенность с методом
   `krause_2020_calibrated`; для драгоценных металлов продолжает действовать
   текущий metal floor.
6. Логика размещается в общем оценщике, поэтому приложение, каталог, Избранное и
   Текущий аукцион не получают собственных формул.

До построения quality gate и проверки модели на отложенной выборке fallback из
Краузе в production добавлять нельзя.

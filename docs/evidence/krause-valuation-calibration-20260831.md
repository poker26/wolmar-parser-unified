# Калибровка цен Краузе для единой оценки — 2026-08-31

## Граница проверки

Проверка выполнена на production БД в режиме read-only. Снимки оценок не
создавались, связи лотов и каталог не изменялись. Использован текущий production
release `/var/www/wolmar-current` и общий `ValuationService`.

Воспроизводимые инструменты:

- `domain/krause-reference.js` — единая работа с выпусками и ценами Краузе;
- `scripts/audit-krause-price-quality.js`;
- `scripts/calibrate-krause-ruble.js`.

## Исправление источника данных

Первый проход аудита использовал `coin_type.ref_prices`. Это было неверно:
действующий каталог намеренно не публикует это поле и строит таблицу Краузе как
медиану `ref_issues[].prices` по каждому грейду. Все выводы первого прохода
отменены. Цифры ниже получены только из канонического `ref_issues` тем же общим
модулем, который теперь использует API каталога.

Поле `ref_issues` хранит выпуски/варианты монеты, а не ошибки импорта.

## Покрытие канонических данных

- Типов с выпусками Краузе: 68 133.
- Типов, у которых хотя бы один выпуск содержит цену: 53 956.
- Типов с прямой ценой `XF40` или `XF`: 22 352.
- Консервативный quality gate отклоняет 3 853 типа из-за некорректных чисел или
  убывающей шкалы цен по состояниям.
- После гейта остаётся 19 331 тип с ценой XF.
- У 16 614 из них нет пригодных аукционных продаж.

Распределение прямой цены XF остаётся подозрительно широким: P01 = $0,15,
медиана = $60, P99 = $12 500, максимум = $36 250 000. Следовательно,
монотонность необходима, но не гарантирует корректность извлечённого числа.

## Пилотная калибровка

Выбрано 246 типов, стратифицированных по источнику Краузе, диапазону цены XF и
числу пригодных продаж. Для каждого типа общий production-оценщик был вызван без
записи результата.

- Оценка получена для 231 типа, отказ — для 15.
- Только 47 пар имели не менее пяти аналогов и confidence не ниже 0,75.
- На этих 47 парах выполнена пятиблочная кросс-проверка: каждый тип ровно один
  раз был контрольным и не участвовал в обучении своего прогноза.

Результат глобального множителя:

- покрытие: 100%;
- медианная ошибка: в 2,383 раза;
- P90 ошибки: в 43,336 раза;
- в диапазон ×2 попало 36,2% контрольных типов.

Результат сегментов `диапазон цены Краузе + группа металла`:

- покрытие: 57,4%;
- медианная ошибка: в 2,046 раза;
- P90 ошибки: в 6,103 раза;
- в диапазон ×2 попало 48,1% рассчитанных типов.

Дополнительное ограничение ценой внутри обучающего диапазона снизило покрытие до
42,6% и не улучшило ошибку: медиана стала 2,184 раза.

## Решение

Цены Краузе сейчас не используются как fallback текущей рыночной оценки.
Глобальный множитель и проверенная простая сегментация не прошли контрольную
выборку. Подключение любого из них создало бы уверенно выглядящую, но часто
ошибочную пользовательскую цену.

Краузе остаётся:

- авторитетным источником типов и выпусков;
- отдельной исторической справочной таблицей в каталоге;
- потенциальным дополнительным сигналом будущей модели, но не заменой
  аукционным проходам.

## Условия повторного решения

К вопросу fallback можно вернуться после выполнения всех условий:

1. введён более сильный контроль извлечения цен, способный отсеивать не только
   немонотонные шкалы, но и правдоподобно возрастающие ошибочные числа;
2. накоплена существенно более крупная проверенная выборка `тип → проходы`, в
   том числе за счёт стандартных аукционов;
3. качество связей контрольных типов подтверждено отдельно от качества цен
   Краузе;
4. новая модель проверена на отложенных типах и показывает пригодную ошибку при
   полезном покрытии.

Если эти условия будут выполнены, fallback должен размещаться только в общем
`ValuationService`, возвращать широкий диапазон, пониженную уверенность и
отдельный метод. Собственных формул в приложении, каталоге, Избранном или Текущем
аукционе быть не должно.

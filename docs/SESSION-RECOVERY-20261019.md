# Повторный вход после истечения сессии

Пользователь продолжает работу с коллекцией после того, как сервер перестал принимать прежнюю сессию. Приложение открывает форму «Войдите снова» с заполненной почтой. Кнопка «Назад» возвращает к открытой монете.

## Сохранность работы

Ответ 401 не запускает выход из аккаунта. Коллекция, оригиналы фотографий, черновики и очередь синхронизации остаются на устройстве. Приложение сохраняет признак необходимости входа между запусками. Каталог остаётся доступным.

После входа в прежний аккаунт открытая карточка и её поля остаются на месте. Синхронизация продолжает работу с очередью этого аккаунта. При входе в другой аккаунт приложение показывает его коллекцию. Работа прежнего владельца остаётся в его локальном хранилище.

Приложение различает истёкшую сессию и неверный пароль. Ответ запроса, отправленного до нового входа, не должен сбрасывать новую сессию. Пока требуется вход, фоновые запросы не повторяют обращения с истёкшей сессией.

## Проверки

Android покрывает ответ 401 через рабочий сетевой обработчик, повторный вход, неверный пароль, смену аккаунта, сохранность фотографии и запоздалый ответ старой сессии. Соседние тесты проверяют добавление монеты и синхронизацию перед оценкой.

iOS проверяет оценку, удаление, сохранность очереди, оригинала и черновика, повторный вход и запоздалый ответ. Проверка интерфейса снимает две стороны, получает 401, закрывает форму входа, повторяет действие, входит и продолжает определение с теми же фотографиями. Эти тесты должны пройти на симуляторах iPhone и iPad.

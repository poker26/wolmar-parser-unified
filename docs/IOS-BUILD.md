# Сборка Нуми для iOS

## Codemagic

Репозиторий `poker26/wolmar-parser-unified` подключён к Codemagic.
Идентификатор приложения: `6aa5d821dec254f32d6d7dcf`.
Ветка сборки: `codex/collection-mvp-stage-a`.
Workflow: `numi-ios-first-light`.
Конфигурация находится в корневом `codemagic.yaml`.

Workflow проверяет приложение на симуляторе iPhone, затем собирает подписанный IPA.
В исходниках реализованы вход, сохранение сессии в Keychain, локальный альбом,
ручная синхронизация, карточка монеты с тиражом, оценкой и проходами,
поиск и обзор коллекции. Эта версия предназначена для просмотра существующей коллекции.
Добавление и редактирование монет ещё требуют переноса с Android.

Тесты проверяют применение изменений, повторную загрузку локальной коллекции,
разделение данных аккаунтов и восстановление сессии. Тест интерфейса открывает
альбом, карточку с тиражом и обзор, затем проверяет поиск. Для интерфейсного
теста используются синтетические записи. Реальный аккаунт и физический iPhone
требуют отдельной проверки.

## Доступ через API

Скрипт `scripts/codemagic-ios.ps1` получает список приложений и сборок, запускает
сборку и читает её статус и логи. Токен передаётся через `CODEMAGIC_API_TOKEN`
или `CM_API_TOKEN`. Поддерживается пользовательская переменная Windows
`CODEMAGIC_API_TOKEN`.

В этой рабочей среде существующий токен ботанического проекта сохранён в
`C:\Users\hippo\historical-recipes\.claude\settings.local.json`.
Скрипт может прочитать его через `-CredentialSettingsPath`; значение токена
в команды и документацию не вставляется.

```powershell
$credentials = 'C:\Users\hippo\historical-recipes\.claude\settings.local.json'
.\scripts\codemagic-ios.ps1 -Action Builds -AppId 6aa5d821dec254f32d6d7dcf -CredentialSettingsPath $credentials
.\scripts\codemagic-ios.ps1 -Action Start -AppId 6aa5d821dec254f32d6d7dcf -CredentialSettingsPath $credentials
.\scripts\codemagic-ios.ps1 -Action Status -BuildId <build-id> -CredentialSettingsPath $credentials
.\scripts\codemagic-ios.ps1 -Action Log -BuildId <build-id> -StepId <step-id> -CredentialSettingsPath $credentials
```

После сетевой ошибки при запуске сначала нужно проверить список сборок.
Codemagic мог принять запрос до разрыва соединения. Повторный запрос создаст ещё одну сборку.

## Структура проекта

В `android-app/iosApp` находятся приложение SwiftUI и описание проекта XcodeGen.
Клиент использует URLSession, Keychain и локальные файлы в Application Support.
API-контракт соответствует Android-клиенту. Фотографии загружаются при
синхронизации и сохраняются локально. Просмотр альбома читает локальные данные.
Карточка загружает проходы при первом открытии и сохраняет ответ для просмотра
без сети; кнопка обновления запрашивает свежие данные.

В `android-app/iosTests` и `android-app/iosUITests` находятся тесты Xcode.
Каталог `android-app/ios-shared` содержит прежний проверочный каркас Kotlin;
текущий проект Xcode собирает SwiftUI-приложение самостоятельно.

Сценарий Codemagic сохраняет IPA как артефакт сборки. Для передачи в TestFlight
потребуются запись приложения в App Store Connect и настройка публикации.

## Загрузка в TestFlight

Workflow `numi-ios-testflight` наследует все проверки и сборку из
`numi-ios-first-light`. После успешного завершения тестов и подписи он
загружает IPA в App Store Connect через секретные переменные группы `appstore`.
Параметр `submit_to_testflight` управляет отправкой на beta review,
а не самой загрузкой. Его значение `false` оставляет сборку для внутреннего
тестирования. Отправка в App Store требует отдельного решения о релизе.

13 сентября официальный API Apple подтвердил Bundle ID
`ru.begemot26.numismat` с идентификатором `B35FLYSNGW`.
Запрос `/v1/apps?filter[bundleId]=ru.begemot26.numismat` вернул HTTP 200
и пустой список. Новую запись приложения Apple требует создать на сайте.
Средства управления браузером завершились ошибкой
`failed to write kernel assets: Системе не удается найти указанный путь. (os error 3)`.
Ошибка повторилась после сброса браузерной сессии и через Computer Use.

Запись приложения создана пользователем 14 сентября: платформа iOS,
название «Нуми», основной язык Russian, Bundle ID `ru.begemot26.numismat`,
SKU `226`, Apple ID `6811801085`.
После создания сначала нужно получить Apple ID приложения через API,
затем запустить workflow:

```powershell
.\scripts\codemagic-ios.ps1 -Action Start -AppId 6aa5d821dec254f32d6d7dcf -Workflow numi-ios-testflight -CredentialSettingsPath $credentials
```

После загрузки нужно проверить статус обработки сборки в Apple API и
предоставить пользователю доступ через внутреннюю группу TestFlight.
Источники настройки:
https://docs.codemagic.io/yaml-publishing/app-store-connect/
https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app

14 сентября пользователь выбрал название `Numi` для App Store.
Повторная проверка API подтвердила существующий App ID `B35FLYSNGW`:
Bundle ID `ru.begemot26.numismat`, описание `ru begemot26 numismat`,
платформа `UNIVERSAL`, prefix `9J4X6PJX56`.
Запись приложения в App Store Connect по этому Bundle ID пока отсутствует.

## Установка на iPad Air 2

14 сентября Windows обнаружила подключённый iPad по USB. API Apple подтвердил
модель iPad Air 2 (A1567). Устройство уже зарегистрировано в команде разработчика
и имеет статус `ENABLED`. Пользователь сообщил версию iPadOS 15.8.8.

Workflow `numi-ios-adhoc` собирает приложение для зарегистрированных устройств.
Он наследует тесты и сборку из `numi-ios-first-light`, но получает профиль
`IOS_APP_ADHOC`. Параметр `DeviceUdid` скрипта `codemagic-ios.ps1` передаёт
идентификатор устройства в переменную сборки `NUMI_TEST_UDID`.

Сборка `6aa7c0ffb1bd5dd6b2f854ed` прошла тесты приложения. Создан профиль
`2R2R6TF9TM`. Проверка профиля остановила сборку, потому что искала файл
в прежнем каталоге Xcode. Коммит `d83972c` добавил текущий каталог
`Library/Developer/Xcode/UserData/Provisioning Profiles`.
API Apple подтвердил присутствие iPad в созданном профиле.

Повторная сборка `6aa7c3f6adc5c40c7276d862` завершилась успешно.
Тесты, проверка наличия устройства в профиле и экспорт Ad Hoc прошли.
IPA проверен командой:

```powershell
py scripts/inspect-ios-ipa.py <IPA> --device-udid <UDID> --device-ios 15.8.8
```

`scripts/ios-install-page.py` создаёт Apple-манифест и страницу установки.
Для размещения выбран существующий HTTPS-сервер
`https://flora.begemot26.ru:8443/`, каталог `/var/www/macpub`.
Приложение имеет семейство устройств iPhone и будет запускаться на iPad
в режиме совместимости. Физический запуск требует пользовательской проверки.

iPad в профиле и совместимость заявленной минимальной версии с iPadOS 15.8.8.
Профиль действует до 6 июля 2027 года.
SHA-256 файла:
`c28a8e9f798e758536794cda75e7596550436d35e7e5e3e858800d1223702357`.

Страница установки:

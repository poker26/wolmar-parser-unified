# Источники для пополнения каталога монет

Проверено по публичным страницам 4 сентября 2026 года. Цель списка — обнаружение типов монет,
прежде всего выпусков с 2019 года. Цены магазинов в каталог и ценовую аналитику не переносим.
Для иностранных монет зарубежные каталоги, эмитенты и монетные дворы приоритетнее российских
магазинов; российские площадки удобны для обнаружения и русскоязычного названия.

## Контрольные источники, не магазины

- [Банк России: ежегодный каталог памятных монет 2025](https://cbr.ru/content/document/file/187846/coins_cbr_2025_pr.pdf) — первичное подтверждение российских выпусков.
- [Raritetus: навигация по годам современной России](https://www.raritetus.ru/stoimost-monet/god/) — дополнительная классификация выпусков 2019–2026; цены не использовать.
- [United States Mint](https://www.usmint.gov/learn/coins-and-medals/commemorative-coins), [Royal Canadian Mint](https://www.mint.ca/en/discover/canadian-commemorative-circulation-program), [The Royal Mint](https://www.royalmint.com/annual-sets/2025-annual-sets/), [Perth Mint](https://www.perthmint.com/) и [ЕЦБ](https://www.ecb.europa.eu/) — первичные источники по своим выпускам.
- Для иностранного кандидата перед публикацией желательно подтверждение на сайте центрального банка,
  государственного или контрактного монетного двора либо минимум двумя независимыми магазинными карточками.

## Правила общего магазинного адаптера

1. Сохранять карточки в `auction_lots` как наблюдения с новым `source_site`; наличие товара не является фильтром.
2. Не переносить магазинную цену: `winning_bid=NULL`. Статус использовать только как `active` или `archived`/`ended_unsold`.
3. Сохранять исходный URL, устойчивый ID/артикул, полный заголовок и доступные оригинальные фото.
4. До матчинга отсекать банкноты, медали, жетоны, реплики, сувениры, аксессуары и многомонетные наборы.
5. Сначала прогонять общий `coin-matcher`; только причина «нет типа» создаёт `catalog_candidate`.
6. Не публиковать кандидат автоматически. Одной карточки достаточно для очереди, но не для подтверждения типа.
7. Перед разработкой адаптера отдельно проверить `robots.txt`, условия использования, частоту запросов и наличие sitemap/API; эта проверка пока не выполнена.
8. Источник, адаптер, расписание, доступность и каждый запуск фиксировать в `catalog_source` и `catalog_source_run`; площадки не удалять физически, а переводить в `retired`.

## Управление реестром

```bash
node catalog/source-registry.js list
node catalog/source-registry.js list --status proposed --kind shop
node catalog/source-registry.js show numizm.at
node catalog/source-registry.js set-status numizm.at probing
node catalog/source-registry.js set-access numizm.at allowed
node catalog/source-registry.js set-adapter numizm.at numizmat-shop
node catalog/source-registry.js schedule numizm.at "1 day"
node catalog/source-registry.js due 50
node catalog/source-registry.js retire old-shop.example "магазин закрыт"
```

Команда `retire` сохраняет карточки кандидатов и историю запусков. Очередь `due` содержит только
источники в состояниях `probing` и `active`, у которых наступил `next_poll_at`.

## Порядок пилота

1. Российская дорожка: по 100 карточек 2019–2026 годов с numizm.at, UniCoin и CoinsBolhov.
2. Иностранная дорожка: проверить условия доступа Numista, затем по 100 карточек с EMK и Power Coin.
3. Отчёт: распознано монет, отброшено наборов/жетонов, сматчено с каталогом, создано кандидатов, совпало между источниками.
4. Ручная проверка 30 наиболее подтверждённых кандидатов по карточкам и фотографиям.
5. После оценки точности — полный проход новых выпусков и затем архивов.

# Интернет-магазины для пополнения каталога монет

Проверено по публичным страницам 4 сентября 2026 года. Цель списка — обнаружение типов монет,
прежде всего выпусков с 2019 года. Цены магазинов в каталог и ценовую аналитику не переносим.

## Контрольные источники, не магазины

- [Банк России: ежегодный каталог памятных монет 2025](https://cbr.ru/content/document/file/187846/coins_cbr_2025_pr.pdf) — первичное подтверждение российских выпусков.
- [Raritetus: навигация по годам современной России](https://www.raritetus.ru/stoimost-monet/god/) — дополнительная классификация выпусков 2019–2026; цены не использовать.
- Для иностранного кандидата перед публикацией желательно подтверждение на сайте центрального банка,
  государственного или контрактного монетного двора либо минимум двумя независимыми магазинными карточками.

## Правила общего магазинного адаптера

1. Сохранять карточки в `auction_lots` как наблюдения с новым `source_site`; наличие товара не является фильтром.
2. Не переносить магазинную цену: `winning_bid=NULL`. Статус использовать только как `active` или `archived`/`ended_unsold`.
3. Сохранять исходный URL, устойчивый ID/артикул, полный заголовок и доступные оригинальные фото.
4. До матчинга отсекать банкноты, медали, жетоны, реплики, сувениры, аксессуары и многомонетные наборы.
5. Сначала прогонять общий `coin-matcher`; только причина «нет типа» создаёт `catalog_candidate`.
6. Не публиковать кандидат автоматически. Одной карточки достаточно для очереди, но не для подтверждения типа.
7. Перед разработкой адаптера отдельно проверить `robots.txt`, условия использования, частоту запросов и наличие sitemap/API; эта проверка пока не выполнена.

## Порядок пилота

1. По 100 карточек 2019–2026 годов с каждого из трёх источников первой очереди, без записи в `coin_type`.
2. Отчёт: распознано монет, отброшено наборов/жетонов, сматчено с каталогом, создано кандидатов, совпало между источниками.
3. Ручная проверка 30 наиболее подтверждённых кандидатов по карточкам и фотографиям.
4. После оценки точности — полный проход новых выпусков и затем архивов.
